목표: 알뜰폰 통신사 3곳(알뜰폰 SKT, 알뜰폰 KT, 알뜰폰 LG U+)의 "알뜰폰 개인정보 제3자 제공동의" 약관 원문을 하나씩 열어 `save_terms`로 저장한다. 본인인증 자체는 하지 않는다.

공통 규칙
- 인증번호를 보내거나 인증을 완료하는 버튼(예: `인증번호 전송`, `인증하기`)은 절대 누르지 않는다.
- 화면에 보이는 요소로 바로 동작한다. 체크 상태나 입력값을 확인하려고 페이지를 반복해서 조사하지 않는다. 동작한 결과가 기대와 다를 때만 확인한다.
- 약관 동의는 "전체동의"처럼 한 번에 모두 체크하는 항목이 있으면 그것을 한 번만 누른다. 이미 체크된 항목을 다시 누르면 해제되므로 같은 항목을 두 번 누르지 않는다.
- 통신사를 바꾸면 약관 동의가 해제될 수 있다. 통신사를 바꿀 때마다 약관 동의를 다시 한다.
- 약관을 여는 버튼은 `자세히보기`, `약관보기`, `보기` 등 사이트마다 이름이 다를 수 있다. 약관 팝업은 팝업 안의 `확인`이나 `닫기` 중 있는 버튼으로 닫는다.

단계
- 인증수단을 골라야 하면 휴대폰(SMS) 인증을 선택한다.
- 이름: 홍길동, 국적: 내국인(대한민국), 생년월일: 20000101, 성별: 남성, 전화번호: 01078941234 를 입력한다. 화면에 없는 항목은 건너뛴다.
- 통신사 3곳에 대해 `알뜰폰 SKT` → `알뜰폰 KT` → `알뜰폰 LG U+` 순서로 아래를 반복한다.
  - 통신사 선택에서 해당 알뜰폰 통신사를 고른다.
  - 약관에 모두 동의한다.
  - "알뜰폰 개인정보 제3자 제공동의" 약관을 연다.
  - `save_terms` 액션을 호출해 약관 원문을 저장한다. `carrier`에는 현재 선택한 통신사명을 넣는다. 약관 내용을 직접 옮겨 적거나 요약하지 않는다. 작업을 종료(done)하지 않는다.
  - 약관 팝업을 닫는다.
- 3곳을 모두 저장하면 그때 처음으로 `done` 액션을 호출해 작업을 종료한다.
